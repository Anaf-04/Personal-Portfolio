Final Year Project

Raspberry Pi 4

Serves as the edge compute hub inside the bin, running FaceID verification, YOLOv8 waste classification, and sensor polling entirely on-device.

HC-SR04 & HX711

Pairs an ultrasonic proximity sensor that wakes the camera only when a user is within 40cm with a load cell that measures the weight delta confirming an item was actually deposited.

dlib

Extracts a 128-dimensional FaceID embedding on the edge device for user identification, discarding the raw image immediately so no face photo is ever stored.

Supabase

Stores encrypted face embeddings with pgvector for cosine-similarity matching, and handles Auth, Edge Functions for reward logic, and the points transaction ledger.

Flutter

Powers the companion mobile app used for FaceID registration, a user dashboard, and redeeming recycling reward points.

YOLOv8

Classifies each deposited item as recyclable or non-recyclable from a high-speed camera burst captured at the moment of disposal.

  • A smart IoT recycling bin that pairs computer vision, facial recognition, and physical weight sensing on a Raspberry Pi to fix contamination and low engagement in public recycling.
  • Prevents "drop-and-pull" reward fraud by only awarding points when the YOLOv8 waste classification and a stable positive weight delta from the load cell agree.
  • Keeps biometrics privacy-preserving: dlib extracts a 128-d face embedding on-device, the raw image is discarded immediately, and only the encrypted vector is synced to Supabase.
  • Uses interrupt-driven power management, keeping the camera and AI pipeline asleep until the HC-SR04 sensor detects a nearby user, to save energy and limit camera exposure.
  • Closes the loop with a Flutter mobile app for FaceID registration and redeeming points earned from correctly recycled items.

YOLOv8 / Darknet

The planned defect-detection model the annotation workbench is built to feed: snapshots get hand-labeled and exported in YOLO format as training data for it.

NVIDIA Jetson

An edge deployment target the app has also been run on, alongside its primary Windows desktop environment on the factory floor.

  • DAINVI is an internal industrial visual-inspection platform built for Dalantia Technology, giving factory floor staff a browser-based tool to monitor production cameras and build labeled datasets for defect-detection models.
  • Streams live video from factory cameras with start/stop recording and snapshotting, then feeds captured frames into a manual annotation workbench for bounding-box labeling and defect tagging.
